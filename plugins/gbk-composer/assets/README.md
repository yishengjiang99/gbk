# Assets

**Icon placeholder:** the ChatGPT listing icon is owner-supplied and pending. Drop it here as `icon.png` (square) and add the reference to `plugin.json` `interface` at that time.

No logo, icon, or screenshot assets are bundled with this plugin package yet.

`plugin.json` deliberately does not reference any icon, logo, or screenshot
files, because none exist in this repository for the plugin. Do not add
references to asset files until the real files exist here.

When real brand assets are available, place them in this directory, for
example:

- `logo.png` — the GBK Composer logo (real artwork supplied by the project
  owner, not generated placeholders or third-party art)
- `icon.png` — a square plugin icon
- `screenshots/` — real captures of the GBK Studio workstation and the
  embedded player / piano-roll component

After adding a real asset, update `plugin.json` (and any marketplace or
submission metadata) to reference it, and verify the referenced path exists
before submitting the package anywhere.
